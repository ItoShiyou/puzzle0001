# puzzle0001 — パズルゲーム モック集 (v3)

スマホ/タブレット縦持ち前提。ツムツム・ぷにぷにのように「毎日ついやりたくなる」ことを最優先にした、
盤面型パズルのモック5案。`index.html` をブラウザで開くと遊べます（ビルド不要）。

## 共通のやり込みの仕組み（`mocks/common.js`）
1. 1プレイ60秒、盤面は無限補充
2. 大きく消すとボム。消すほどスキル・フィーバー（得点2倍）ゲージがたまる
3. スコア→コイン→なかまガチャ（新キャラ）／レベルアップ（スキル強化）
4. きょうのミッション（毎日3つ）＋ベストスコア
5. キャラごとに固有スキル（IPキャラを載せる枠）。コイン・キャラは5作共通（localStorage）

## 5つのパズル（盤面ルールだけが違う）
| # | 名前 | ルール | 考えどころ |
|---|------|------|-----------|
| 01 | わっかつなぎ | なぞり消し＋線を閉じると内側も全消し | 輪を作れる場所を探す |
| 02 | しんかチェーン | 同キャラ同レベルをなぞって進化、Lv★で同キャラ全消し | 進化の置き場所とタイミング |
| 03 | くるりん4 | 交点タップで4体回転、2×2四角でつながり全消し | 回す順番、落下連鎖 |
| 04 | おしだしパズル | 端から押し込み、押し出された子が次の手持ち | 先読み |
| 05 | はさみけし | 同キャラ2体で一直線にはさむと、あいだも全消し | 長くはさめるペア探し |

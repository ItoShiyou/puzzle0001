# puzzle0001 — パズルゲーム モック集 (v2)

スマホ/タブレット（iOS・iPadOS・Android）縦持ち前提で、
「同じ盤面ルールでも毎回結果が変わる」「キャラ（IP）を載せ替えて展開できる」「ショート動画映えする」
パズルのモック5案。v1（既存作に近い型）から方針を変え、コアの操作そのものが新しいものに絞っています。

`index.html` をブラウザで開くと一覧から遊べます（ビルド不要・素のHTML/Canvas・WebAudioで音あり）。

| # | 名前 | コア操作 | 新しさ | 動画映え |
|---|------|---------|--------|---------|
| 01 | ハミング・チェイン | 1タップ | 連鎖＝毎回違うメロディ | 音が主役、1タップで合唱 |
| 02 | インク・フリック | 弾く | 結果が「一枚の絵」になる | 完成絵をそのまま投稿 |
| 03 | オービット・ライン | 狙って撃つ | 回転盤面で「そろう一瞬」を見極める | 直列ビームの瞬間 |
| 04 | バブル・キャッチ | 長押し | 欲張りチキンレース | ぎりぎりの緊張と大漁 |
| 05 | ころころ装置 | 置いてGO | 組み立て→眺める2段構成 | 眺める部分がそのまま動画 |

## 構成
- `mocks/common.js` … 9:16 キャンバス、オリジナル仮マスコット描画（`MASCOTS`）、演出、効果音
- `mocks/0X-*.html` … 各モック
- キャラは `MASCOTS`（色＋アクセサリ）で表現。IPキャラの立ち絵に差し替える想定

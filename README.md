# puzzle0001 — パズルゲーム モック集

スマホ/タブレット（iOS・iPadOS・Android）縦持ち前提で、ツムツム・ぷにぷに・パズドラのように
「同じ盤面ルールでも毎回結果が変わる」「キャラ（IP）を載せ替えて展開できる」「ショート動画映えする」
ことを狙ったパズルのモック5案です。

`index.html` をブラウザで開くと一覧から各モックを遊べます（ビルド不要・素のHTML/Canvas）。

| # | 名前 | コア操作 | ランダム性の源 | 動画映えポイント |
|---|------|---------|---------------|-----------------|
| 01 | もちもち合体ドロップ | 落とす | 物理の転がり・次キャラ | 連続進化・最終キャラ誕生 |
| 02 | ペグ・フィーバー | 狙って撃つ | 盤面生成・バウンド | ラスト1個のスロー＆FEVER |
| 03 | ドカーン連鎖 | 1タップ | 配置・落下補充 | 1タップで画面全消し |
| 04 | くるりんボード | 盤面回転 | 降ってくるキャラ | 盤面ごと回る＋連鎖 |
| 05 | ひっぱりポップ | 引っぱって弾く | 玉突きの物理 | 一打でドミノ的に弾ける |

## 構成
- `mocks/common.js` … 9:16 キャンバス、キャラ描画、パーティクル・バナー・画面揺れなど共通演出
- `mocks/0X-*.html` … 各モック
- キャラは `CHARS` / 各ファイルの配列にある絵文字の仮置き。IPキャラ画像に差し替える想定
